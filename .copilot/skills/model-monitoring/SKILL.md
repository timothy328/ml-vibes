# Model monitoring

Check API health and latency, input schema validity, missing values, feature
drift, prediction class balance, probability distributions, and delayed-target
performance. Compare measurements with a documented baseline and time window.

Recommend retraining only for sustained drift, meaningful metric regression,
class-balance changes, or a changed data-generating process. Report the
baseline, observed value, threshold, and recommended action.
